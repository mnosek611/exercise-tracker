How to Update on GitHub:

  1. Save the code above into a file named index.html on your computer.
  2. Go to your repository on github.com (mnosek611/exercise-tracker).
  3. Click on your existing index.html file, click the pencil icon to Edit (or upload the new file over the old one).
  4. Click Commit changes. GitHub Pages will update your live app within 1 minute!
